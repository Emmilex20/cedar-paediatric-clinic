# Cedar Paediatric Clinic — Website Concept

A responsive website concept prepared for Cedar Paediatric Clinic in Kaduna, Nigeria.

> This repository currently contains an independent demonstration/proposal and is not yet the clinic's official website.

## Included in the concept

- Responsive mobile-first clinic website
- General paediatrics and paediatric neurology presentation
- Parent-friendly service discovery
- Appointment request demo flow
- Contact and opening-hours presentation
- Privacy-conscious messaging
- Clear concept/demo disclosures
- Vercel-ready Next.js setup

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Production

The project can be imported directly into Vercel from this GitHub repository.

Clinic-specific service descriptions, official address, phone numbers, clinician profiles, opening hours and appointment workflow should be confirmed by Cedar Paediatric Clinic before an official launch.
